# Food Delivery Time Prediction

## Deskripsi

Proyek ini bertujuan untuk memprediksi waktu pengantaran makanan berdasarkan berbagai fitur yang tersedia dalam dataset. Dengan menggunakan teknik Machine Learning, model ini diharapkan dapat memberikan estimasi waktu pengiriman yang lebih akurat.

## Dataset

Dataset yang digunakan dalam proyek ini dapat diunduh dari Kaggle melalui link berikut: [Food Delivery Time Prediction Dataset](https://www.kaggle.com/datasets/denkuznetz/food-delivery-time-prediction/data)

## Struktur Repository

- `FoodDeliveryFIX.ipynb`: Notebook utama yang berisi eksplorasi data, preprocessing, dan model prediksi.
- `Take Home Test DS28 Presentation.pptx`: Presentasi yang menjelaskan hasil dari proyek ini.

## Cara Menjalankan

1. Clone repository ini:
   ```bash
   git clone https://github.com/FaizAbiyyu/Food-Delivery-Time-Prediction.git
   ```
2. Install dependensi yang diperlukan:
   ```bash
   pip install -r requirements.txt
   ```
3. Unduh dataset dari Kaggle dan tempatkan dalam direktori yang sesuai.
4. Jalankan notebook menggunakan Jupyter Notebook atau Google Colab.

## Teknologi yang Digunakan

- Python
- Pandas & NumPy untuk manipulasi data
- Scikit-learn untuk model Machine Learning
- Matplotlib & Seaborn untuk visualisasi

## Hasil dan Kesimpulan

Model yang dikembangkan mampu memberikan estimasi waktu pengantaran makanan dengan tingkat akurasi yang baik. Detail hasil dapat ditemukan dalam notebook dan presentasi yang tersedia dalam repository ini.
